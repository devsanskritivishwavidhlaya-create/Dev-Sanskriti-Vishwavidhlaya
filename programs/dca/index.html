Diploma in Computer Application (D.C.A.)

A comprehensive 2-semester (1-year) diploma program providing hands-on proficiency in computer operations, office productivity suites, C programming, database management, and modern web designing.

2 Semesters 1 Year Duration

Program Overview

The Diploma in Computer Application (D.C.A.) at Dev Sanskriti Vishwavidyalaya is designed to empower students with foundational and practical IT skills necessary for modern workplace environments. The curriculum blends theoretical computer science concepts with extensive practical lab sessions, enabling students to gain immediate professional employability.

Students master operating systems, office automation tools, database handling, structured programming in C, accounting packages like Tally, and foundational web design technologies, providing a strong launchpad for employment or higher IT studies.

Core Study Areas

Computer Fundamentals
Office Automation (MS Office)
Database Management & SQL

Semester-wise Curriculum

Semester 1: Fundamentals of IT & Office Applications

Core Subjects:

  • Computer Fundamentals & Operating Systems — Hardware, memory, Windows 11, Linux CLI basics
  • PC Packages & Office Automation — Word processing, spreadsheet analysis in Excel, PowerPoint
  • Database Fundamentals — Relational concepts, MS Access tables, forms, queries and reports

Practical / Lab:

  • Hands-on laboratory training on PC packages, documentation, and database operations

Semester 2: Programming, Web Development & Accounting

Core Subjects:

  • Programming Methodology & C Language — Control structures, arrays, pointers, functions, files
  • Web Technology & Internet Applications — HTML5, CSS3, JavaScript basics, hosting
  • Financial Accounting with Tally — Vouchers, ledger entries, GST management, balance sheets

Practical / Lab:

  • C Programming Lab, Web Page Design Project, Tally Practical & Viva Voce
