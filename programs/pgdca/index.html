Postgraduate Diploma Program

Post Graduation Diploma in Computer Application (P.G.D.C.A.)

An advanced 2-semester (1-year) postgraduate diploma designed for graduates from any discipline seeking mastery in software development, modern programming, database systems, and enterprise web solutions.

2 Semesters 1 Year Duration
Graduation Any Stream (45%)
₹7,500 Per Semester Fee

Program Overview

The Post Graduation Diploma in Computer Application (P.G.D.C.A.) at Dev Sanskriti Vishwavidyalaya is a specialized technical conversion program that transforms graduates into competent software professionals. The program provides in-depth exposure to object-oriented programming, modern database architecture, web technologies, software engineering, and operating systems.

With an emphasis on industry-aligned programming languages (C++, Java, Python) and live software project development, PGDCA enables graduates to transition smoothly into the rapidly expanding information technology and software services sector.

Core Study Areas

Object-Oriented Programming (C++)
Core Java & OOPs
RDBMS & SQL (MySQL / Oracle)

Semester-wise Curriculum

Semester 1: Foundations of Advanced Computing & Databases

Core Subjects:

  • Advanced Programming with C++ — Classes, inheritance, polymorphism, templates, exception handling
  • Relational Database Management Systems (RDBMS) — Normalization, SQL, PL/SQL, indexing, transaction processing
  • Data Structures & Algorithms — Stacks, queues, linked lists, binary trees, sorting & searching
  • Operating Systems & Linux — Process scheduling, memory management, shell scripting, Linux utilities

Practical / Lab:

  • C++ Programming Lab & RDBMS/SQL Lab with industry problem statements

Semester 2: Web Technologies, Enterprise Java & Capstone Project

Core Subjects:

  • Java Programming & Web Applications — Core Java, Applets/Swing, JDBC connectivity, Servlets basics
  • Web Technologies — HTML5, CSS3, JavaScript, PHP / Python web basics, REST APIs
  • Software Engineering & Project Management — Agile methodology, UML modeling, software testing, QA
  • Computer Networks & Information Security — OSI model, TCP/IP, network protocols, cryptography basics

Practical / Lab:

  • Java & Web Technologies Lab, Major Software Development Project & Comprehensive Viva
